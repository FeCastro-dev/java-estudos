# ☕ Estudos em Java

Repositório dedicado aos meus estudos de Java, com exercícios e atividades práticas desenvolvidos durante o curso **Java COMPLETO — Programação Orientada a Objetos + Projetos**, ministrado por Nélio Alves.

## 🎯 Objetivo

Consolidar meus conhecimentos em Java por meio da prática, desenvolvendo raciocínio lógico, compreensão dos fundamentos da linguagem e aplicação dos conceitos de programação orientada a objetos.

Este repositório também registra minha evolução ao longo do curso, incluindo exercícios de fixação e resolução de problemas.

## 📚 Conteúdos estudados

- Fundamentos da linguagem Java
- Estruturas condicionais e de repetição
- Classes, objetos e métodos
- Construtores e encapsulamento
- Vetores e matrizes
- Manipulação de datas e horários (em andamento)

## 🛠️ Tecnologias e ferramentas

- Java
- Visual Studio Code
- Git e GitHub

## 📈 Evolução

O repositório é atualizado conforme avanço no curso, buscando aplicar os conceitos estudados e desenvolver soluções próprias para os exercícios propostos.
